## MyKorr

A self-hosted information relay for portable esp32 communicators.

**Status:** Prototype / WIP / Proof-of-concept

---

### Quick start

1. Clone
```bash
git clone https://github.com/USERNAME/MyKorr.git
cd MyKorr
```

2. Run
```bash
go run ./cmd/server/main.go
```
